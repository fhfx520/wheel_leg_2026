# SPI 支持包验证

日期：2026-10-25。

- 实际 `spi_log.c` 的原生模拟测试通过：调用方缓冲区复制、接收就绪门控、
  DMA 完成后续发、启动失败重试、队满拒绝、非法长度、错误恢复与会话变化。
- H723 隔离完整工程使用本目录日志、故障、NMI、status 和 SPI 后端构建，
  ArmClang 6.24 编译链接通过，0 错误、0 警告。
- MAP 确认 DMA 暂存区为 `0x2404E000`、768 字节、32 字节对齐；
  故障 UNINIT 位于 `0x2001F000`，占 2504/4096 字节。
- 验证工程基于现有云台工程，保留其独立 USB 业务来满足其他模块依赖；
  该 USB 业务不是本包日志的发送后端。SPI 包源码无需 USB 头文件或类库。
- USB 分支使用拆分前原文件，另行完成 H723 完整构建，0 错误、0 警告。

测试与构建证据在 F405 工作区 `diagnostics/user_add_spi_split`：
`run_test.cmd`、`spi_build.log`、`usb_build.log`、两个验证工程及 MAP。

未修改实际主板应用工程，未烧录硬件。主机 12 Mbit/s、接收端缓冲区、
接收就绪通知、SD 卡阻塞、故障重启和 D-Cache 实机验证仍待执行。
本地 DMA 完成不能证明记录板已接收或落盘。
